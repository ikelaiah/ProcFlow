# ProcFlow v1.14.0 — Scale and convergence

Released as the `v1.14.0` scale and convergence milestone.

## Highlights

- Extracted confidence policy and large-input UI policy into focused modules.
- Added deterministic large-input, estate, graph, report, and realistic-corpus
  coverage.
- Added iterative large-graph cycle traversal and responsiveness protection at
  100,000 characters.
- Hardened Mermaid and draw.io metadata handling against hostile input.
- Added immutable GitHub Actions pins, Dependabot configuration, issue forms,
  Firefox smoke, runtime packaging, and package startup smoke.
- Reorganised documentation and published the v1.14 metrics snapshot.

## Verification

The final local verification recorded for this release includes:

- 213/213 deterministic browser assertions on `tests/index.html`;
- 400/400 deterministic fuzz cases;
- 31/31 UI interaction checks;
- 5/5 security checks;
- 11/11 scalability and realistic-corpus checks;
- `npm run typecheck`, `npm run build`, `npm run test:file`, `npm run metrics`,
  `npm run benchmark`, and `npm run package:smoke` passing;
- strict pilot typecheck passing for the extracted policy modules;
- runtime archive structure and local-file startup smoke passing.

The Firefox workflow is included in CI; Firefox was not available in the local
verification environment. The workflow captures a browser screenshot after the
critical-path page has run its runtime assertions.

## Accuracy and limits

The heuristic accuracy contract is unchanged from v1.13.0. Dynamic SQL remains
opaque, catalogue and column resolution remain conservative, and the final
accuracy contract is intentionally deferred to v2.0.0. See
[ACCURACY.md](../ACCURACY.md) and [metrics-v1.14.0.json](../metrics-v1.14.0.json).

## Upgrade and distribution

The runtime is self-contained. Use `npm run package:runtime` to produce the
versioned ZIP and verify `.release/SHA256SUMS.txt` before distributing it.

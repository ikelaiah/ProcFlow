# ProcFlow v1.14.1 — Targeted correctness patch

ProcFlow v1.14.1 is a focused post-release correctness patch for the
v1.14.0 scale and convergence release. It contains only the three reproduced
accuracy fixes from the post-release audit; no new dialects or product
features were added.

## Correctness fixes

- **PL/pgSQL named `LATERAL` sources remain visible.** Dependency analysis now
  retains a named function/table source following `LATERAL` instead of
  silently omitting it.
- **DB2 prepared/dynamic SQL stays conservative.** `PREPARE ... FROM` no longer
  treats its statement expression as an object read, and DB2 `EXECUTE` is
  represented as opaque dynamic SQL rather than a static procedure call.
- **DB2 `SESSION.` temporary-table flow is preserved.** A unique sequential
  producer now retains its conservative producer → consumer `data` edge for a
  `SESSION.` global temporary table.

Each correction has a minimal failing-first regression fixture. Existing
neighbouring semantic outputs remain unchanged; the complete accuracy record
is in [ACCURACY_GAPS.md](../ACCURACY_GAPS.md).

## Upgrade

The runtime remains local-first and self-contained. Download
`procflow-v1.14.1.zip`, keep `index.html`, `styles.css`, `dist/`, and
`vendor/` together, and verify the SHA-256 entry in `.release/SHA256SUMS.txt`.

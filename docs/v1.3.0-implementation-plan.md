# v1.3.0 Implementation Plan — Trust procedural control flow

Branch: `feature/v1.3.0`. Source of truth: `ROADMAP.md@264-273` (v1.3.0),
`ROADMAP.md@101-119` (Workstream B), `ROADMAP.md@413-441` (verification
strategy), `.github/workflows/correctness.yml`.

## 1. Acceptance criteria

From `ROADMAP.md` v1.3.0 release section and Workstream B:

1. **Mixed `IF`/`WHILE`** — one-line and block forms parse into one AST; graph-edge
   fixtures cover the mixed forms (`ROADMAP.md@270`, `@105`).
2. **Labelled loop-control + `GOTO` hardening** — labels carry source spans; targets
   are validated for scope and kind; nested-loop behaviour preserved; unresolved
   targets get a `goto_unresolved` region-scoped diagnostic **and** an explicit
   "unresolved label" node instead of a silent drop (`@107-109`, `@270-271`).
3. **Cursor query bodies** — DB2 `FOR` cursors and T-SQL `DECLARE … CURSOR`
   represented consistently in query graphs, while the existing object-level cursor
   read extraction is preserved (`@110-112`, `@271`).
4. **DB2 `ATOMIC` block rollback scope** — modelled in the graph (`@113`, `@271`).
5. **Extended `summarise` label set** — `GRANT`, `WAITFOR`, `KILL`, … (`@114`).
6. **F export parity** — every new procedural construct gets an export-parity
   fixture (`@266-267`).
7. **E procedural diagnostics** — `goto_unresolved` with correct document/region
   scope (`@267-268`); the framework block-keyword ignored list stays closed
   (`@1447-1461`).
8. **Regression** — every existing labelled-loop, `GOTO`, and cursor-read fixture
   stays green; unattributed-token and `unknown` fallback rates stay flat or drop
   (`@272-273`); full CI gate green.

## 6. Correctness commands after each slice

CI gate (`correctness.yml`): `npm ci` → `npm run typecheck` → `npm run build` →
**dist currency** (`git status --porcelain -- dist` empty) → Mermaid checksum →
start static server → golden (`tests/index.html`) → fuzz (`tests/fuzz.html`) →
UI (`tests/ui.html`) via Chromium headless (`--virtual-time-budget=20000`,
`--dump-dom`, `<body class="pass">`) → local-only HTTP grep.

Local equivalent after each slice:
```powershell
npm run typecheck
npm run build
git status --porcelain -- dist   # must be clean
npm run test:file
# start a static server on :8000, then Chromium headless against:
#   tests/index.html (golden), tests/fuzz.html (fuzz), tests/ui.html (ui)
```

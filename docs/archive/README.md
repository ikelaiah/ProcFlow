# Archived documentation

These files are kept for provenance. They record how ProcFlow reached its
current state, but they are **not** maintained and may describe superseded
behaviour, versions, or file paths.

- **Release and PR notes** (`RELEASE_NOTE_*`, `PR_NOTE_*`) for v1.0–v1.13 were
  duplicated and were superseded by `docs/releases/vX.Y.Z.md` and
  `CHANGELOG.md`, which are the canonical history from v1.14.0 onward.
- **`v1.3.0-implementation-plan.md`**, **`V2_ACCURACY_CONTRACT_DRAFT.md`**, and
  **`ACCURACY_GAPS.md`** are historical planning or audit documents.

For current documentation, start from the documentation index in
[`../../README.md`](../../README.md) and [`../RELEASES.md`](../RELEASES.md).
